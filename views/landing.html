ก้าวสู่การเป็น
นักพัฒนา

เขียนโค้ด ทำภารกิจ และบริหารชีวิตการทำงาน เพื่อเอาตัวรอดในโลกของนักพัฒนา

เกี่ยวกับเกม

เกมนี้คืออะไร?

เกมแบบผู้เล่นหลายคน ที่ทักษะการเขียนโค้ดของคุณจะกำหนดเส้นทางการเล่น

💻

เขียนโค้ด

แก้โจทย์การเขียนโปรแกรมด้วยการเติมฟังก์ชันที่ขาดหายไป และทำให้โปรแกรมทำงานได้อย่างถูกต้อง

🎯

ทำภารกิจ

รับงานแบบสุ่ม ทดสอบคำตอบของคุณ และส่งงานเมื่อทำสำเร็จ

☕

เอาตัวรอด

บริหารความเครียดและความหิว เพื่อให้สามารถทำงานต่อได้

วิธีการเล่น

HOW TO SURVIVE AS A DEVELOPER

เรียนรู้การทำงานและเอาตัวรอดในโลกของนักพัฒนา

01

ค้นหาคอมพิวเตอร์

เดินไปหาคอมพิวเตอร์ที่ยังว่าง แล้วกด E เพื่อเป็นเจ้าของเครื่อง

02

รับภารกิจ

กดปุ่ม Start Random a Task เพื่อรับโจทย์งานแบบสุ่ม

03

เขียนโค้ด

เขียนฟังก์ชันที่โจทย์กำหนด ลงในช่องที่เตรียมไว้ และเลือกภาษาโปรแกรมมิ่งได้ที่ Language

04

รันและทดสอบ

ใช้ตัวแปรที่โจทย์เตรียมไว้ เพื่อทดสอบฟังก์ชัน แล้วกด Run เพื่อดูผลลัพธ์

05

ส่งงาน

ตรวจสอบผลลัพธ์ด้านล่าง หากถูกต้องให้กด Submit เพื่อส่งงาน

06

นำกล่องปริศนาไปส่ง

หลังจากส่งงาน คุณจะได้รับ Mystery Box นำกล่องไปส่งให้หัวหน้า

07

อย่ายอมแพ้

หากยอมแพ้กับโจทย์นี้ สามารถกด Give Up ได้ แต่จำไว้ว่าในกล่องปริศนา ข้อมูลไม่ถูกต้องแน่นอน...

☕ จัดการความเครียดและความหิว

บริหารความเครียดและความหิวของคุณให้ดี เติมกาแฟเมื่อรู้สึกว่าความเครียดสูงเกินไป เพราะถ้าเครียดเกินไป คุณจะทำงานต่อไม่ไหว!

เลือกระดับความท้าทาย

โหมดการเล่น

เลือกรูปแบบการเล่นที่เหมาะกับคุณ

MODE 01

โหมดสำนักงาน

เริ่มต้นชีวิตนักพัฒนา รับงาน เขียนโค้ด และทำงานร่วมกับผู้เล่นคนอื่น

  • ภารกิจแบบสุ่ม
  • โจทย์การเขียนโปรแกรม
  • ผู้เล่นหลายคน
  • รางวัล
MODE 02

โหมดฮาร์ดคอร์

โหมดสำหรับผู้เล่นที่ต้องการ ความท้าทายที่มากขึ้น

  • โจทย์ที่ยากขึ้น
  • แรงกดดันที่สูงขึ้น
  • Greater รางวัล
  • ประสบการณ์แบบฮาร์ดคอร์
ชีวิตของคุณ การตัดสินใจของคุณ

ชีวิตนักพัฒนา

💻

การเขียนโค้ด

เขียนโค้ดและแก้ไขโจทย์ เพื่อทำงานให้สำเร็จ

😰

ความเครียด

ความเครียดเพิ่มขึ้นจากการทำงาน จัดการก่อนที่จะสูงเกินไป

🍔

ความหิว

อย่าปล่อยให้ความหิว ทำให้ประสิทธิภาพในการทำงานลดลง
