คุณถูกจ้างเข้ามาทำงานในบริษัท Overcoded

คู่มือฉบับนี้บอกว่า

1.เมื่อเริ่มเกม ให้ไปหาคอมพิวเตอร์ที่ยังว่าง กด E เพื่อเป็นเจ้าของมัน

2.สุ่มโจทย์งาน โดยการกดปุ่ม Start random a task

3.งานที่ได้มา จะให้เราเขียนฟังก์ชันที่ขาด ลงในกล่องที่แบ่งไว้ให้ตามวัตถุประสงค์ที่โจทย์ต้องการ และนำมาเรียกใช้ที่กล่องสุดท้าย โดยผู้เล่นสามารถเลือกภาษาโปรแกรมมิ่งที่จะใช้เขียนได้ด้านบนขวามือที่หัวข้อ Language

4.ทุกๆโจทย์จะมีการกำหนดตัวแปรมาให้เรียกใช้งาน เพื่อใช้ Test ฟังก์ชันที่เราเขียน และแสดงผลลัพธ์ออกมาด้วยเมื่อกดปุ่ม Run

5.ตรวจสอบผลลัพธ์ที่แสดงด้านล่าง ถ้าถูกต้องตามโจทย์ก็กดปุ่ม Submit เพื่อส่งงานได้เลย!

6.หลังจากส่งงานแล้ว คุณจะได้กล่องปริศนาออกมา ให้คุณนำเอากล่องนี้ไปส่งให้หัวหน้า ถ้าคุณมั่นใจว่าโค้ดของคุณถูกต้องก็ไม่ต้องกังวล แต่ถ้าโค้ดของคุณผิดล่ะก็...

7.ปุ่ม Give up สำหรับในกรณีที่ยอมแพ้กับข้อนี้แล้ว แต่ก็รู้ไว้ด้วยว่าภายในกล่องปริศนาที่ได้รับมา ข้อมูลไม่ถูกต้องแน่นอน..

**บริหารความเครียดและความหิวของคุณให้ดี เติมกาแฟเมื่อรู้สึกความเครียดสูงเกินไป ถ้าเครียดเกินคุณทำงานต่อไม่ไหวหรอก
